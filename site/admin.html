    How this site works

    Articles live on the Blogger blog. The public website reads them automatically — no redeploys, ever.

    Where do I change things?

    • Write / edit articles — Blogger editor (Dashboard tab → shortcuts), or Quick post here.
    • Homepage rows, videos, quote, footer, menu — Site Settings tab, then Save.
    • Logo image & blog menus — Blogger → Layout.
    • Colors — Blogger → Theme → Customize.

    Labels are the magic

    A post labelled News appears in the Updates row; Featured puts it in the top carousel. One post can carry several labels. Every post needs at least one image — the first image becomes its thumbnail.

    Where do my settings get saved?

    Into a hidden page on the blog called SITE-CONFIG. Both the Vercel site and the blog read it when they load. Don’t delete that page, and never put passwords in it — it is technically public.

    Sign-in doesn’t work?

    The Google OAuth Client ID must be set in config.js and this page’s address must be listed as an authorized JavaScript origin in Google Cloud Console (SETUP.md has the exact steps). Only the Google account that owns the blog can actually save — other accounts get an error from Google.
